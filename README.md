# AI Emotion Lab

AI가 감정을 **느낀다고 주장하지 않고**, 고정 합성 카드의 관찰 가능한 상황 신호로 안전하고 일관된 다음 행동을 선택하는 결정론적 참조 구현입니다.

## 시작점

- 현재 v0.1: 진행자가 선택한 P01–P12 카드만 받으며, `G0 → G1 → P1 → P2 → P3 → P4` 우선순위로 행동과 인계 여부를 결정합니다.
- 검증: 잘못된 입력은 G0 안전 인계로 닫고, 긴급·경계 위험은 역할극보다 먼저 중단·진행자 인계합니다. 출력은 템플릿만 사용합니다.
- 성공 기준: 고정 카드에서 결정론적 결과와 안전 게이트가 회귀 시험과 일치하는 것입니다. 실제 사용자 효용이나 인간 정서 재현을 주장하지 않습니다.
- 제외: 원문 대화 해석, 장기 기억, 외부 LLM, 멀티모달 감정 추론, 치료·채용·감시·고위험 의사결정.

`affect_development` 패키지는 appraisal·감쇠 상태·조절·기억 기록 스키마·발달형 카드의 **결정론적 참조 구현**입니다. 이는 별도 연구 경로이며, v0.1 역할극 정책의 완료 주장이나 주관적 감정·인간 발달의 증거가 아닙니다. LLM 어댑터와 장기 개인 기억은 여전히 구현 범위 밖입니다.
