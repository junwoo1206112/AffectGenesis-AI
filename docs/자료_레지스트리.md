## 수집 규칙

1. 우선순위는 원 논문·공식 표준·공개 재현 저장소 순이다.
2. 각 새 항목에는 DOI/영구 링크, 저자·연도, 접근일, 라이선스/이용 조건, 주장, 반증 가능성, 프로젝트 사용 위치를 기록한다.
3. 논문에서 단일 결과를 일반화하지 않는다. 이론 자료는 구현 사양의 근거이지 인간 감정의 사실 판정이 아니다.
4. 데이터셋은 동의, 재배포 권한, 인구집단 편향, 삭제 경로가 확인되기 전에는 내려받거나 Git에 넣지 않는다.

## 다음 읽기 순서

R01·R02로 표현/모듈 경계를 정하고, R03으로 appraisal 변수 후보를 좁힌다. R04·R05는 상태가 정책에 주는 이득을 실험할 때만 사용한다. R06은 멀티모달 확장을 막는 안전 체크리스트로 쓰며, R07·R08은 전 단계의 위험 원장과 평가 설계에 적용한다.
