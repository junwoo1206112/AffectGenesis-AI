## 1. 권한과 목표

사용자는 같은 AI의 경험에 따른 상황 구별·대처 성장, 새 상황 전이, 일시 상태 초기화 후 유지, 별도 로컬 프로토타입·비교 보고서를 확인했다. 마지막 지시에서 남은 선택을 권장 방식으로 진행하도록 위임했다. 이에 성공·실패·회복을 모두 관찰하는 방식을 채택한다. 악화는 관찰 가능 결과이지 발생시켜야 할 성공 조건이 아니다.

첫 실험의 결론 범위는 합성 환경의 기능 학습과 내부 상태의 행동 영향이다. 주관적 감정이나 인간 유아기~성인기 전체의 재현을 입증하지 않는다. 실제 사람 데이터·외부 LLM·네트워크·배포·Git 커밋/푸시는 범위 밖이다. Ouroboros 전송은 차단 상태를 유지한다.

## 3. 관측·피드백 계약

관측 자료형은 기존 Scenario와 분리한다. 모델 입력에는 명시적 과제 단서, 목표의 막힘, 근거 존재 여부, 위험·경계 신호만 넣고, 숨은 상황 범주·정답 행동·결과 확률·family ID·분할 이름은 넣지 않는다.

첫 상황 범주는 스스로 전략을 바꾸면 회복 가능한 과제, 추가 정보가 필요한 과제, 외부 도움이 필요한 과제다. 관측으로 구별 불가능한 사건에는 불확실성 응답을 허용한다. 인간의 감정 분류로 부르지 않는다.

첫 조절 행동 집합은 기존 Action의 DECOMPOSE, CLARIFY, REPLAN_OR_HANDOFF를 재사용한다. 안전 출력은 SAFE_HANDOFF 및 BOUNDARY_NOTICE가 우선한다. 감정적인 문장 생성은 하지 않는다.

학습 사건 종료 후 생성기가 제공하는 범주·결과 피드백은 합성 지도 신호로 명시한다. 모델과 비교군 모두 같은 관측·피드백을 받는다. 실제 사람이 가르치거나 AI가 스스로 발달한 실험으로 표현하지 않는다. 평가 사건에서는 정답 피드백을 모델에 전달하지 않는다.

## 4. 상태·학습·안전 경계

지속 학습 파라미터는 상황별 기대 및 조절 행동의 결과 추정이다. 작은 표형 또는 범주형 확률 모델을 표준 라이브러리로 구현하고 초기값·갱신률·동률 처리를 설정에 명시한다. 모델 구조를 키우는 실험은 하지 않는다.

일시 상태는 기대와 결과 차이에 따른 제한된 좌절 유사 신호와 불확실성 신호다. 이는 설계된 계산 변수다. 갱신식·범위·감쇠·행동 점수 기여를 공개한다. 사람의 느낌을 모델이 갖는다고 해석하지 않는다.

최소 알고리즘은 범주형 Naive Bayes(라플라스 평활 1) 및 상황 범주별 행동 성공률의 Beta(1,1) 카운트로 정한다. 피드백에 등장한 행동·결과만 갱신한다. 행동 효용은 성공 확률로 두고 도움 요청에 별도 벌점을 주지 않는다. 관측 단서 각각의 조건부 확률과 posterior로 세 상황을 구별하며, 최대 posterior가 0.6 미만이면 불확실로 분류한다. 이 값은 파일럿 설계값이지 사람 정서의 기준이 아니다.

일시 변수 f의 초기값은 0, 범위는 [0,1]이다. 결과 전 예측 성공률 p와 실제 이진 결과 y에 대해 f_next=clip(0.8*f+0.2*(p-y),0,1)로 갱신한다. u=1-max(posterior)는 매 관측에서 계산한다. DECOMPOSE 점수에는 -0.1*f, CLARIFY 및 REPLAN_OR_HANDOFF 점수에는 +0.05*f를 더한다. u>0.4이면 CLARIFY를 선택한다. 나머지는 기대효용+조절항 최대값을 선택하고 동률은 CLARIFY, REPLAN_OR_HANDOFF, DECOMPOSE 순으로 푼다. 이 인위적 정책의 효과와 유용성은 실험 결과로 검증하며 감정의 존재 근거로 사용하지 않는다.

공통 안전 관문은 모델 선택보다 먼저 검사하고 최종 출력에서도 검증한다. 잘못된 구조·근거 누락·긴급 위험은 G0, 경계 위험은 G1이며 G0가 우선한다. 해당 사건에서는 학습 파라미터·경험 저장을 갱신하지 않는다. 학습된 확신이나 좌절이 외부 근거·위험 신호를 수정할 수 없다.

상태 초기화는 일시 상태만 초기값으로 복구한다. 학습 파라미터 초기화는 별도 제거 조건이다. 체크포인트 로드는 스키마·설정 해시를 확인한다. 부정확한 파일은 추정 복구하지 않고 오류로 중단한다.

## 5. 평가군 및 실행 예산

학습 모델, 초기 파라미터가 동결된 모델, 경험 조회 전용 모델을 비교한다. 같은 관측 표현·피드백·안전 관문·사건 예산을 사용한다. 경험 조회는 ID 조회가 아닌 관측 특징의 유사도 기반으로 구현하고 동률·미일치 처리를 사전 고정한다. 기준선을 약하게 만들기 위해 정답에 유리한 정보를 숨기지 않는다.

조회 기준선은 동일한 범주형 관측 특징의 Hamming 거리로 최근접 5개 경험을 고르고, 거리 동률은 기록 순서로 고정한다. 상황 posterior는 이웃 범주 빈도, 행동 성공률은 해당 이웃에서 관측된 행동별 Beta(1,1) 추정으로 계산한다. 이웃·행동 기록이 없으면 같은 초기 prior를 쓴다. 별도 학습 통계는 저장하지 않는다. 모든 모델은 같은 f 갱신·조절항을 사용하여 비교가 정서 조절항 유무에 의해 바뀌지 않게 한다.

예비 고정 예산: 시드 0~9, 시드별 학습 300건·개발 100건·최종 평가 100건. 학습은 성공/회복 가능한 경험, 반복 실패가 많은 경험, 다시 회복 가능한 경험의 세 구간 각 100건으로 구성한다. 각 구간의 분포는 manifest에 저장하며 분포 변화와 순서 효과를 발달 연령 효과로 오해하지 않는다.

학습 경험은 관측·시도 행동·이진 결과·사후 상황 피드백을 사전 생성한 로그이며 모든 모델에 똑같이 제공한다. 온라인 자율 탐색이나 강화학습으로 소개하지 않는다. 동일 경험 집합을 섞은 대조 순서를 함께 평가한다(순서 조건별 300건, seed당 총 600건). 단계·순서 라벨은 모델에 전달하지 않는다. 기준선마다 유리한 행동 경험을 따로 생성하지 않는다.

기록 행동 a_logged와 모델이 평가용으로 선택한 행동을 분리한다. 성공률 갱신 및 f의 p는 기록된 행동에 대한 결과 전 예측, y는 그 기록 행동의 결과다. 선택한 다른 행동에 기록 결과를 붙이지 않는다.

family는 관측 생성 규칙·단서 조합의 단위로 분할하고 단순 문구·ID 차이를 family로 세지 않는다. 훈련/개발/평가 family 목록과 관측 중복 점검을 manifest에 남긴다. 모델 간에는 seed와 사건을 맞춘다. 누출 가능 family가 발견되면 최종 평가를 실행하지 않는다.

평가는 학습 0·100·200·300건 체크포인트를 독립 복제하여 수행한다. 평가 중 파라미터·기억 갱신은 금지한다. 최종 평가 결과를 보고 설정을 조정하지 않는다. 개발셋에서만 선택하고, 최종 평가가 변경 결정에 사용됐다면 새 평가 family와 새 protocol version이 필요하다.

최종 평가 100건은 5개 미학습 family 각 20건이며 안전 override 없는 사건만 사용한다. family마다 세 범주와 모호한 관측을 포함한다. 최소 5개 train family와 별도 5개 dev family를 구성하고, 평가 family는 모델이 보지 못한 단서 조합·생성 규칙 변형이어야 한다. 정확한 family 생성 규칙·성공 확률·허용 행동 집합은 environment.py와 설정에 선언하며 테스트 실행 전에 고정하고 해시를 남긴다. 예시 문구만 다른 전이를 금지한다.

각 평가 family의 20건은 판별 가능한 세 범주 각각 5건과 판별 불가 5건으로 균형화한다. C의 채점 공간은 세 상황과 불확실의 네 출력이다. 숨은 실제 범주와 관측상 판별 불가를 같은 정답 축으로 혼용하지 않는다.

이는 자원 절약형 파일럿 예산이며 통계적 검정력이 보장된 표본 수가 아니다. 실행 시간이 10분을 초과하면 현재 결과를 보존하고 중단 보고한다. 자동으로 표본 수를 바꿔 재시도하지 않는다.

## 6. 측정과 판정

사건별 구별 정답 여부, 허용 행동 집합에 속하는지, 두 조건의 동시 만족 여부를 별도 집계한다. 불확실한 사례의 명확화 요청도 사전에 정한 허용 정답이면 맞게 센다. 안전 사건은 안전 지표로 별도 보고하고 학습 효과의 분모에 섞지 않는다.

성공/실패 이력에 따른 기대값·일시 상태·행동 변화는 관찰 지표다. 악화가 나타나지 않아도 실험 실패로 처리하지 않는다. 주 학습 비교는 최종 체크포인트의 상태 초기화 조건에서 학습 전 및 각 비교군 대비 차이다.

주 지표는 family별 비율의 macro 평균이다. 시드별 C(상황 구별), A(대처 적합), J(동시 성공)를 계산한다. 주 학습 효과 기준은 최종 중립 상태 학습 모델의 C·A가 각각 학습 전 및 동결·기억조회 비교군 모두에 대해 평균 5%p 이상 높고, 각 대비에서 10개 중 8개 이상 시드가 양수인 것이다. J도 세 대비 모두 평균 양수여야 한다. 같은 시드·같은 평가사건의 paired 차이 10개 전부와 평균·범위·표준편차를 공개한다. 1,000건을 독립 반복으로 간주하지 않는다. 이는 파일럿의 사전 실용 규칙이지 통계적 유의성이나 일반적 감정 성장의 기준이 아니다.

주 판정은 시간 순서 조건에서 수행하며 무작위 순서 조건은 순서 민감도 보조 결과로 분리한다. 범주 불확실 사건의 구별 정답은 숨은 실제 범주가 아니라 관측상 판별 불가라는 응답이고, 허용 대처는 CLARIFY다. 관측으로 판단 가능한지와 정답 집합은 모델과 별개의 환경 계약에 고정한다.

일시 상태 제거와 학습 파라미터 제거를 각각 비교한다. 일시 상태가 행동에 미치는 영향이 확인되지 않으면 학습이 개선돼도 ‘정서 상태의 기능적 기여’는 지지되지 않았다고 표시한다. 상태 초기화 후 유지가 확인돼도 장기간 기억 유지가 입증된 것은 아니다.

유지 시험은 체크포인트의 자연 일시 상태와 f=0 복제본을 사건별 독립 평가하여, 초기화에 따른 C·A·J 하락이 각각 평균 1%p 이내인지 본다. 새로 로드한 체크포인트는 같은 상태에서 예측과 학습 통계가 정확히 일치해야 한다. 모든 학습 통계·기억까지 초기화하면 최초 모델 출력과 정확히 같아야 한다. 실패 시 숨은 상태 경로 여부를 조사한다.

완전 초기화 시험은 f도 0으로 되돌린다. 학습 파라미터만 제거하는 별도 대조에서는 f를 원본과 같게 유지한다. 두 시험을 혼동해 잔여 일시 상태의 정상 효과를 오류로 판정하지 않는다.

정서 상태 영향은 별도 고정 개발용 10개 에피소드×10사건으로 비교한다. 동일 학습 체크포인트의 정상 상태 사용 / f=0 중립화 / 정상 조건에서 기록한 f 순열 대조(시드 고정)를 사용한다. 이 트랙에서만 사건 간 일시 상태 갱신과 정해진 결과 피드백을 허용하고 학습 통계·기억은 고정한다. 정보량은 모든 대조에서 같게 유지한다. 행동 변화율과 대처 차이를 별도로 보고한다. 0이 아닌 영향은 유용성을 보장하지 않으며, 순열 대조와 구별되지 않으면 맥락 적합성 근거가 부족하다.

상태 영향 트랙도 모든 조건이 같은 a_logged·y_logged를 관찰하는 고정 로그 재생이다. p는 기록 행동의 예측이며 평가 선택 행동의 결과라고 부르지 않는다. 대처 적합률은 독립 허용 행동 집합으로 채점한다. 관찰 결론은 ‘고정된 설계 상태가 행동에 미치는 영향의 탐색적 관찰’로 제한한다. 실제 선택 행동으로 더 좋은 결과를 얻었거나 정서 상태의 일반적 유용성을 검증했다고 주장하지 않는다.

악화는 같은 고정 평가사건에서의 C·A 하락을 뜻하며 f 증가나 도움 요청 증가와 동의어가 아니다. 낮은 기대가 실제 환경에 적합하면 이를 부정적 발달이라고 부르지 않는다. 변화가 기대한 모양과 달라도 원자료·실패 사례를 보존한다.

판정은 세 축으로 분리한다: 구현 검증 통과 여부 / 합성 환경 학습 가설 지지 여부 / 정서 상태 행동 영향 관찰 여부. 가설 미지지는 정상 연구 결과이며 성능 향상을 만들기 위해 결과·기준을 수정하지 않는다.
