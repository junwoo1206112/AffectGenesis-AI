# 실패·회복 이력이 필요한 환경 — 교차검토 중간 초안

후속 상태(2026-09-20 20:14 KST): 사용자 재개 승인 후 기존 검토자 3명을 재사용하여 교차검토 완료. 최신 권장안은 [환경 권장 명세](시간적_경험_환경_권장_명세.md)다. 아래 중단·미확정 기록은 당시 이력으로 보존하며 현재 장애를 뜻하지 않는다.

2026-09-20 19:07 KST. 상태: 미확정·구현 없음·교차검토 중단. 사용자 요청은 전문가 인터뷰 스킬과 AI 역할 교차검토를 통한 권장 환경 설계다. 인간 전문가 자문은 아니다.

## 인터뷰 범위와 미확정 사항

- 목적: 과거 실패·회복 경험이 다음 판단에 도움이 되는 합성 환경에서 기억의 효과와 기능적 정서 상태의 기여를 구분한다.
- 기존 합의 유지: 로컬·합성 데이터만, 외부 LLM 연결·실제 사람 데이터 없음. 기존 v0.1과 affect_growth 모델/산출물 보존. 이번에는 설계만 진행한다.
- 사용자에게 범위 정리 확인 질문을 보냈으며 이 기록 시점에 응답은 아직 없다. 장기 발달 단계 전체까지 포함했다고 간주하지 않는다.
- 미확정: 환경 수치·에피소드 길이, 정서 후보의 명확한 정의, 공정한 비정서 기억 기준선, 학습/개발/평가 분할, 정량 판정 기준, 복구 개입 효과와 자연 회복의 구분.

## 구조 검토자가 보낸 초기 제안

temporal_architect의 중간 응답이며 최종 합의·통과 판정이 아니다. 수치는 설계 후보이지 문헌 표준이나 실행 결과가 아니다.

- 숨은 작업 상태: G(수행 가능), B(차질). 공개 관측은 동일한 작업 요청이다. 정답 상태·실패/회복 phase·스케줄을 정책 입력에 주지 않는다.
- TRY: G에서 성공 확률 0.9, B에서 0.2. 성공 보상 +1, 실패 -1.
- SAFE: 확정 보상 +0.1. 합성 과제의 보수적 대안이며 기존 긴급 안전 관문과 별개다.
- RECOVER: 즉시 보상 -0.2. 비용과 한 timestep을 소비하며 복구 성공 여부를 직접 알려주지 않는다.
- 비복구 행동 뒤 P(G'|G)=0.95, P(G'|B)=0.10.
- 복구 행동 뒤 P(G'|G)=0.95, P(G'|B)=0.80.
- 모든 행동이 한 timestep을 소비하고, 결과 및 상태 전이의 난수는 분리한다. 실패·복구 자체에 성장 보너스를 주지 않는다.

의도: 같은 현재 요청이라도 최근 시도의 결과로 현재 작업 상태에 대한 추정이 달라진다. 복구 행동은 다음 상태에 영향을 준다. 실제 유용성, 항상 복구/항상 대안 선택의 지배 여부, 정보 획득 가치 및 행동 결과의 공정 비교는 아직 계산·검증하지 않았다.

## 평가 검토자가 지적한 보완점

temporal_metrics의 중간 응답이다. 시간적 지속성만 제거한 IID 대조에서도 행동이 다음 상태에 영향을 주면 과거 행동은 여전히 정보다. 따라서 ‘기억이 쓸모없는 대조’는 매 단계 숨은 상태를 독립적으로 뽑고 행동의 다음 상태 영향도 제거해야 한다. 이 대조는 지속성과 행동 통제 가능성을 함께 제거하는 복합 개입이라고 명시해야 한다. 단일 요인 효과라고 해석하면 안 된다.

## 중단 및 재개

- 세 번째 반론 검토자 생성이 `agent thread limit reached`로 실패했다. 현재 세션에 이전 growth_contrarian도 남아 있다.
- 사용자 오류 시 중단 지시에 따라 추가 검토·설계 확정을 멈추고 실행 중이던 두 검토자를 중단했다. 이미 수신한 중간 제안만 보존했다.
- 재개안: 새 에이전트 생성 대신 기존 growth_contrarian에게 후속 검토를 맡기고, temporal_architect/temporal_metrics의 기존 작업을 이어간다. 아직 이 후속 요청은 보내지 않았다.
- 이후 초안 교차 반박과 보완 → closure의 closer/contrarian/gap_hunter 검토 → 사용자 목표 재확인 순서다. Seed 생성·새 환경 구현을 승인받았다고 간주하지 않는다.
- 인터뷰 MCP 도구는 발견되었지만 기존 외부 전송 제한으로 호출하지 않았다. 도구가 설치되지 않았다고 보고하지 않는다. 스킬과 인터뷰어·Seed Closer 지침은 읽었다. 버전 업데이트·외부 문헌 조회는 수행하지 않았다.
