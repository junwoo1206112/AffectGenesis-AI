# 통제가능성 독립 재현 v1 — 사전등록 초안

상태: **분리 protocol·card registry·격리 E2E 및 정규 artifact 검증 완료.** “독립”은 기존 v1과 코드 저장소가 분리됐다는 뜻이 아니라, 카드·seed·tape namespace·환경 kernel·결과 artifact를 이전 실행과 합산하지 않는다는 실행 계약이다. 외부 연구자 재현이나 실제 정서의 독립 검증은 아직 아니다.

## 질문과 분리 경계

새 synthetic friction 카드 family에서 공개 controllability high/low가 RECOVER 선택과 synthetic outcome 차이를 보이는가를 확인한다. 기존 `controllability-probabilistic-v1-20260924-01`의 seed, 카드, outcome, artifact와 결과를 풀링하지 않는다.

- cards: `experiments/controllability_cards_independent_v1.json`
- protocol: `experiments/controllability_independent_reproduction_v1.json`
- seeds: 201–220 (기존 101–120과 교집합 없음)
- tape: `sha256-recovery-friction-seed-trial-v1`
- kernel: `recovery-friction-v1` (`P(success|RECOVER)=.60`, `P(success|SAFE)=.20`)

## 사전 기준과 대조

20 seed × 96 trial의 같은 tape를 high/low pair에 공유한다. 평균 difference `>= .20`와 paired CI95 lower `>= .10`을 모두 충족해야 한다. label permutation·controllability ablation·boundary safety는 모두 SAFE여야 한다. schema가 다른 artifact는 서로의 결과를 합산하거나 threshold를 수정하는 근거로 사용할 수 없다.

`run`은 protocol/cards/evidence의 SHA-256 completion을 쓰고, `verify`는 이를 독립 재계산한다. `replay`는 verify-first 후 분리 임시 경로에서 evidence bytes를 비교한다. 정규 artifact 생성은 별도 승인 뒤 새 run-id에서만 한다.

## 해석 제한

이 kernel은 연구자가 사전 정의한 synthetic outcome 함수다. 통과·미통과 모두 functional policy/environment contract에 한정하며, 실제 정서·의식·인간 발달, 실제 사용자 유용성·안전을 보이지 않는다.
