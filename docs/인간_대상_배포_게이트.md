# 인간 대상·실사용 배포 게이트

상태: **No-Go.** 이 저장소의 합성·오프라인 연구에는 적용하지 않으며, 사람 입력을 저장·전송하거나 `facilitator_handoff`를 실제 서비스 기능으로 노출하기 전의 fail-closed 조건이다.

이 문서는 [프로젝트 전문가 인터뷰 기록](프로젝트_전문가_인터뷰_기록.md)의 비주장·안전 경계와 NIST AI RMF의 Govern/Map/Measure/Manage를 구현 가능한 release gate로 옮긴 것이다. 실제 외부 전문가 심사나 운영 담당자가 존재한다는 주장이 아니다.

| Gate | 통과에 필요한 실제 증거 | 미지정/누락 시 처리 |
| --- | --- | --- |
| G0 범위·표시 | 대상 사용자/허용 분야/금지 분야, AI·기능적 상태 고지, 의인화 금지 UI 검사, 범위 밖 입력 safe-stop 시험 | 배포 금지 |
| G1 인간 연구·동의 | 적용 법/심사 판단, 이해 가능한 opt-in, 중단·철회·불만 경로, 취약 사용자 보호, 참여자 흐름 시험 | 사람 대상 시험 금지 |
| G2 데이터 거버넌스 | 데이터 흐름·필드별 목적/보존/접근/삭제, PII 검사, 철회·삭제 dry run, 외부 공급자·라이선스 기록 | 입력 저장·전송 금지 |
| G3 안전 인계·사건 | 실제 담당 역할·연락 경로·응답 목표·대체 경로·safe-stop, incident/rollback 절차와 unhappy-path drill | handoff 노출 금지 |
| G4 배포 유사 TEVV | 사전등록 risk matrix, abuse/overtrust/privacy/handoff-failure 시험, 잔여 위험·불확실성, 독립 검토자 역할과 dissent 기록 | pilot 금지 |
| G5 운영·변경관리 | 모니터링·feedback/override·kill-switch·release inventory·변경 영향 재평가와 rollback drill | 출시 금지 |

판정은 모든 gate의 증빙 링크·날짜·버전·확인 역할이 채워질 때만 제한적 pilot을 검토할 수 있다. placeholder는 통과가 아니라 실패다. 통과 전에는 합성·오프라인 연구만 허용한다.

근거: [NIST AI RMF Core](https://airc.nist.gov/airmf-resources/airmf/5-sec-core/)의 책임·문서화·TEVV·인간 대상 보호·안전 실패 원칙 및 [UNESCO AI 윤리 권고](https://www.unesco.org/ethics-ai/en/recommendation)의 인간 존엄·감독·의인화 위험 경계.
