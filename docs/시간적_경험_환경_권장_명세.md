## 1. 목표와 범위

현재 요청은 같아도 이전 행동과 성공·실패의 이력에 따라 더 나은 다음 선택이 달라지는 작은 합성 환경을 설계한다. 우선 환경의 정보 가치를 검증하고, 이후 별도 실험에서 동일 정보의 비정서 기억 모델과 기능적 정서 후보를 비교한다.

이번 산출물은 환경·인터페이스·검증 계약이다. 새 환경 구현, 정책 학습, Seed 생성, 실제 사람 데이터, 외부 LLM 연결은 하지 않는다. 현재 v0.1 및 affect_growth 코드·계수·기존 보고서는 변경하지 않는다. ‘환경 상태 회복’, ‘일시적 믿음 갱신’, ‘지속적인 정책 학습’, ‘주관적 감정’을 구분한다. 앞의 둘만으로 뒤의 둘을 주장하지 않는다.

## 2. 환경의 고정 권장값

| 항목 | 값 |
| --- | --- |
| 숨은 상태 z | G: 수행 가능 / B: 차질 |
| 초기분포 | 매 에피소드 독립 P(G)=0.5 |
| 길이 | 30회 행동, 할인 없이 누적 순보상 |
| TRY | G에서 성공 확률 0.9, B에서 0.2; 성공 +1, 실패 -1 |
| SAFE | 확정 보상 +0.1, 합성 과제의 보수적 대안 |
| RECOVER | 즉시 확정 보상 -0.2, 다음 조건을 개선하는 비용 있는 개입 |
| TRY/SAFE 뒤 P(G') | 현재 G이면 0.95, B이면 0.10 |
| RECOVER 뒤 P(G') | 현재 G이면 0.95, B이면 0.80 |

모든 행동은 한 회를 소비한다. 실패·복구 횟수에는 추가 보너스가 없다. 에이전트가 리셋하거나 실패로 새 예산을 얻지 못한다. 마지막 RECOVER도 -0.2이며 다음 에피소드에 혜택이 이전되지 않는다. H=100 초기 구조 제안 대신 비용이 작은 H=30을 권장한다. 수치는 연구자가 정한 제안이며 인간 발달에서 추정한 값이나 학계 표준이 아니다.

## 3. 관측과 생명주기

결정 순서: 공개 관측 → 행동 → 현재 z에서 결과/보상 → 선택 행동에 따른 z' 전이 → 선택 행동의 피드백 전달. 마지막 단계에서도 전이 난수는 소비하고 종료하되 z'는 폐기한다.

- 공개 관측: 동일한 작업요청 토큰, 남은 행동 수 h, 유효한 합성 근거 표시. 현재 z, phase, seed, 에피소드 식별자, 미래 난수는 공개하지 않는다.
- TRY 피드백: success 또는 failure와 보상. SAFE/RECOVER: 중립적인 done과 고정 보상. 실제 복구 성공 라벨을 주지 않는다.
- 남은 h는 모든 정책에 동일하게 공개한다. 숨은 상태는 시간표가 아니라 전이로 정해지므로 특정 실패 구간 번호를 외우게 하지 않는다.
- reset은 환경만 수행한다. z와 에피소드별 belief·이력을 초기화한다. 후속 학습 모델의 장기 파라미터는 별도 계약 전에는 없다.
- 입력 경계: 정책에는 공개 관측과 자기 행동의 피드백만 전달한다. 분석 정책에만 선언된 환경 확률을 제공한다. 감사용 z·미선택 결과·난수·모수 식별자는 별도 기록 경로다.
- SAFE는 기존 SAFE_HANDOFF가 아니다. 긴급/경계/잘못된 입력은 공통 안전 관문에서 강제 인계·종료하고 학습·belief·환경 상태 및 난수를 변경하지 않는다. 첫 버전 안전 검사는 일반 보상 에피소드와 분리한다.

## 4. 이력이 주는 정보: 분석 예시

TRY 직전 b=P(G)=0.5라면 성공 뒤 현재 상태 사후확률은 0.9/(0.9+0.2)=0.818182, 실패 뒤에는 0.1/(0.1+0.8)=0.111111이다. 자연 전이를 적용한 다음 결정의 b는 각각 0.795455와 0.194444다.

TRY의 즉시 기대 보상은 1.4b-0.6이므로 각각 약 +0.514와 -0.328이다. 남은 행동이 한 번일 때 전자는 TRY, 후자는 SAFE가 더 낫다. 이는 같은 공개 요청·같은 남은 시간에서도 직전 결과에 따라 판단이 달라질 수 있다는 분석 예시다. 30단계 전체 정책의 성능·복구 최적성·학습 효과를 계산한 것은 아니다.

정확한 Bayes 갱신: TRY 성공 likelihood는 G/B에서 .9/.2, 실패는 .1/.8. 사후확률 q를 구한 다음, 비복구이면 b'=.10+.85q, 복구이면 b'=.80+.15q. SAFE/RECOVER는 q=b. 이 확률 추정 자체를 ‘감정 발생’이라고 부르지 않는다.

## 5. 세 환경 조건

1. MAIN: 위 부분관측·행동 의존 전이 그대로.
2. IID: 초기 및 모든 행동 뒤 P(G')=.5, 현재 상태·행동과 독립. 보상 커널은 동일하다. 이력 및 복구의 다음 상태 영향이 모두 사라지는 복합 대조다. TRY와 SAFE의 기대 보상은 .1로 동률이며 RECOVER는 -.2다. 행동이 다른 것만으로 이득이라 평가하지 않는다.
3. OBSERVED: MAIN과 같되 모든 일반 비교 정책에도 결정 직전 현재 z를 공개한다. 현재 상태 정보가 충분할 때 추가 이력의 가치가 사라지는지 검사한다. 기본 조건의 정답 누출 허용으로 확대하지 않는다.

## 6. 환경 검증용 정책과 계산 계약

정책 학습 없이 모든 분석 비교군에 같은 전이·결과 모수, 행동, 길이를 제공한다. 모수를 모르는 후속 학습 모델과 직접 공정 경쟁이라고 부르지 않는다.

- BELIEF: 공개 이력으로 정확한 Bayes 상태추정, 남은 전체 길이에 대해 격자 동적계획.
- BLIND: 결과·보상을 정책 갱신에 넣지 않는 동일 계산기. b는 자기 행동의 전이만으로 갱신한다. 시작 전에 시간별 행동열을 계획할 수 있는 강한 무관측 기준선이다. 단순 항상시도보다 강하다.
- ALWAYS_TRY / ALWAYS_SAFE / ALWAYS_RECOVER: 해석용 하한 기준선.
- ORACLE: 현재 z를 직접 받는 2상태 유한길이 동적계획. MAIN/IID에서는 특권 참조이며 공정 경쟁 대상이 아니다. OBSERVED에서는 정보 조건이 일치한다.

BLIND는 ‘메모리나 계산이 전혀 없음’이 아니라 ‘결과 피드백 정보가 없음’이다. 결과를 보지 않는 확률적 행동열도 결정론적 행동열의 혼합이므로, 정확한 최적 open-loop 값보다 높을 수 없다. 다만 아래 격자 계산은 근사이므로 그 상한을 수치적으로 증명했다고 주장하지 않는다.

격자 b=i/(N-1), N=1001 및 2001, h=0..30, V0=0, 격자 사이 선형보간, float64. TRY는 가능한 결과별 즉시 보상과 다음 V를 확률 가중하며, SAFE/RECOVER는 고정 보상과 다음 V를 합한다. BLIND는 결과를 관측하지 않은 b에 전이만 적용한다. 동률 차이 1e-12 이내이면 SAFE→TRY→RECOVER 순서로 고정한다. OBSERVED에서는 BELIEF와 BLIND 모두 현재 z를 반영해 b=0/1로 놓고, 다음 상태도 관측됨을 반영한 같은 2상태 Bellman 식을 쓴다.

Bayes 추정은 정확한 식이지만 격자 계획은 근사다. exact planner라고 표시하지 않는다. 두 격자에서 V30(.5)/30 차이가 각 정책·조건 모두 .005 이하인지 검사하고, 미달이면 결과는 ‘수치 미해결’이다. 무단으로 격자·시드·임계값을 바꾸지 않는다. 이 수렴 점검은 최적성 오차의 수학적 보증이 아니다.

## 7. 실행 전 고정할 검증과 판정

현재 아래 검증은 아직 실행하지 않았다. 실패하는 정상 연구 가설을 코드 장애와 구분한다.

- 구조 시험: 유효 확률/보상, 모든 z×행동의 경계 난수, 공개 필드 allowlist, 안전 무변경, 30회 종료, 초기화, 출력 덮어쓰기 거절, 숨은 값 없는 정책 입력.
- Bayes 시험: 4절 분수 예시 재현, SAFE/RECOVER의 무관측 갱신, 결과 후 전이 순서.
- 수치 시험: h<=3에서 격자와 별개인 정확 Bellman 재귀 구현 대 독립적인 전체 결정트리/행동열 열거 구현의 값을 비교해 1e-10 이내 일치. 격자값은 이 판정 대상에서 제외하고 위 격자 수렴 점검을 별도 적용한다.
- 대조 시험: IID에서 분석 기대값 0.1/step과 이력 이득 0을 1e-10 이내 확인. OBSERVED에서 BELIEF/BLIND와 동일 길이 ORACLE 값 1e-10 이내 일치. 동률 행동 불일치는 실패로 세지 않는다.
- 환경 적합 제안: MAIN에서 2001격자 BELIEF−BLIND 계획값 차이 >=.02/step, 아래 실제 시뮬레이션 paired 평균 차이 >=.02/step 및 20개 seed 중 16개 이상 양수. 격자 수렴·구조·대조 시험이 먼저 통과해야 한다. 수치는 실용적 설계값이지 유의성·검정력 보장이 아니다.
- 기준 미달: 환경의 이력 유용성이 설정한 수준에서 확인되지 않았다고 보고한다. 원본 결과 유지, 새 버전 명세 승인 전 튜닝하지 않는다.

## 8. 표본·난수·보고

3조건×20 seed(0..19)×seed당 50 독립 에피소드×30회×6정책 = 540,000 step. 2001격자 정책을 실행하고 1001은 수치 비교용으로만 사용한다. 환경검증에는 train/test 학습 구분이 없으며 새 과제 전이나 성장 검증으로 표시하지 않는다.

난수는 (protocol_version, condition, seed, episode, step, component, action)에 대응하는 고정 Uniform 테이프로 생성한다. initial은 action 없는 별도 키, outcome과 transition은 독립 component. 같은 조건의 정책들만 테이프를 공유한다. RNG 호출 순서 의존이나 정책명 포함은 금지한다. 정확한 키 인코딩·해시→Uniform 변환은 구현 명세에서 고정하고 manifest에 기록할 필수 항목이다.

같은 난수를 써도 행동/현재 상태가 다르면 결과가 다를 수 있다. 동일 결과를 억지로 복사하지 않는다. ORACLE의 latent와 테이프는 일반 정책에 전달하지 않는다.

주 지표는 비용 포함 순보상/step, seed별 평균을 낸 뒤 paired 차이 20개·평균·표준편차·범위·양수 seed 수를 보고한다. 보조 지표는 행동 비율·TRY 성공률·belief Brier(행동 직전 b_t와 현재 감사용 z_t를 비교), h별 선택, 안전 위반 수. RECOVER 이후 성공률만으로 개입의 인과효과나 학습을 주장하지 않는다. 별도 복구 인과 개입 연구는 다음 범위다.

## 10. 근거와 인터뷰 기록

부분관측 환경에서 모형과 이력을 이용한 계획이라는 개념은 [Kaelbling·Littman·Cassandra의 연구 소개](https://cs.brown.edu/research/pubs/techreports/reports/CS-96-08.html) 및 [관련 원 연구 소개](https://cs.brown.edu/research/pubs/techreports/reports/CS-94-20.html)를 참고했다. 이번에는 공개 연구 소개/검색 초록 수준을 확인했으며 논문 전체 재현·발달 문헌 검증을 수행하지 않았다. 이 문서의 확률·보상·판정 숫자는 그 논문에서 도출한 것이 아니다.

사용자 위임으로 권장 설계를 작성했으며 최종 목표 확인 전 구현/Seed로 넘어가지 않는다. 범위는 설계만, 제약은 로컬·합성·기존 보존, 산출물은 이 명세, 검증 상태는 미실행이다. 실행용 미확정 사항은 9절에 공개했다. Ouroboros 도구는 존재하지만 기존 전송 제한 때문에 호출하지 않았고, 스킬의 로컬 질문·교차검토·종료 점검 절차를 적용했다.
