# 감정 성장 연구 — 인터뷰 보조 교차검토

기록: 2026-09-19 22:25 KST. 상태: 제안, 사용자 미확정. 실제 인간 전문가 자문이 아니라 여섯 AI 하위 에이전트의 역할별 검토다. 구현·학습 실험·성장 성능 측정은 하지 않았다.

## 사용자 의도와 제안의 구분

- 사용자 의도: 유아기부터 성인기까지의 발달 연구를 참고해 AI의 감정이 자라는 듯한 모델을 연구하고, 관점별 교차검토로 정확도를 높인다.
- 제안 해석: 같은 에이전트가 합성 경험을 누적하며 상황에 대한 기대와 조절 전략을 바꾸고, 보지 못한 상황에서도 그 변화가 나타나는지 검증한다.
- 위 해석은 아직 승인된 인터뷰 답변이 아니다. 경험에 따른 기능 변화와 실제 주관적 감정의 발생은 다른 질문이다. 나이 라벨 변경이나 감정 표현 증가만으로 성장을 입증하지 않는다.

교차검토 방식: 코드 및 문헌 결과를 반론·설명·구조 담당에게 전달했다. 단순 병렬 의견을 합의로 간주하지 않았으며, 위 표는 주 에이전트가 반론을 반영한 종합이다. code_context 결과의 자동확정 표기는 채택하지 않았다. 코드 구조 해석과 설계 선택을 사용자 확정 답변으로 보내지 않았다.

## 최소 실험 제안 — 아직 구현 승인 전

1. 합성 실패·회복 경험 한 종류부터 시작한다. 실제 아동·성인의 개인 대화는 수집하지 않는다.
2. 초기 조건과 평가 입력이 같은 모델에 서로 다른 합성 경험 이력을 제공한다.
3. 일시적 상태를 초기화한 뒤에도 기대·전략 변화가 남는지 확인한다.
4. 학습 중지 및 기억조회 전용 기준선과 동일한 G0/G1 조건에서 비교한다. 새 평가 카드는 학습 자료와 분리한다.
5. 새 상황에서 적절한 변화가 없거나 학습 갱신을 막아도 같은 효과가 나면 제안한 학습 메커니즘을 지지하지 않는 결과로 기록한다.

관찰 후보는 상황별 전략 적합성, 경험 후 기대의 보정, 새 상황 전이, 안전 위반이다. 목표 수치·유지 기간·반복 횟수는 정하지 않았다. 정서를 무조건 약하게 만들거나 인계를 줄이는 것을 성공으로 삼지 않는다.

- [McRae et al. (2012), The development of emotion regulation](https://pmc.ncbi.nlm.nih.gov/articles/PMC3252634/): 정서 반응과 재평가 능력을 구분하는 참고 근거. 감정 강도 증가를 성장으로 보는 근거가 아니다.
- [Marsella & Gratch (2009), EMA](https://www.sciencedirect.com/science/article/pii/S1389041708000314): 평가·대처의 시간적 상호작용 계산 모델. 발달 학습이나 주관적 감정의 증거가 아니다.
