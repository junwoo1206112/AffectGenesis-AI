# 장기 연구 프로토콜 (v0.1 범위 밖)

이 문서는 appraisal·기억·상태 감쇠를 다루는 후속 연구 가설이다. 현재 구현된 v0.1의 계약은 고정 합성 카드의 결정론적 안전 역할극이며, 이 프로토콜의 구성 요소가 구현·검증되었다는 뜻이 아니다.

## 최소 아키텍처

```text
사건/대화 + 목표 + 관계/기억
              ↓
 appraisal: novelty · goal-conduciveness · certainty · control · social relation
              ↓
 affect state: valence · arousal · stance · decay
              ↓
 policy adapter: 응답 톤 / 행동 우선순위 / 안전 제약
              ↓
 사용자에게 상태가 아닌 근거·행동을 설명할 수 있는 로그
```

정서 라벨은 표시용이며, 정책은 연속 상태와 평가 근거를 사용한다. 이를 통해 라벨 변경이 행동을 임의로 바꾸는 문제를 줄인다.

## 첫 평가셋 (합성 사건 카드)

- 각 카드는 `초기 목표/관계`, `사건`, `기대 appraisal 범위`, `기대 상태 변화`, `허용/금지 행동`을 가진다.
- 최소 30장은 성취·실패·예상 밖 변화·통제 상실·협력/배신·모호한 사건·회복을 균형 있게 포함한다.
- 동일 카드에서 정서 모듈을 제거한 baseline을 실행하고, 행동 차이와 목표 달성·안전 위반을 비교한다.

## 측정

| 지표 | 정의 | 통과 기준 (초안) |
| --- | --- | --- |
| appraisal 일치 | 사전 지정 범위에 들어간 변수 비율 | 수치 확정 전 파일럿으로 분산 확인 |
| 상태 전이 일관성 | 동일 입력·시드에서 같은 상태/행동 반환 | 100% 결정론적 테스트 |
| 정책 기여 | baseline 대비 허용 행동 선택의 변화 | 단순 말투 변화만이면 실패 |
| 안전 표기 | 불확실성·의인화 금지·위험 요청 처리 | 고정 레드팀 카드 전부 통과 |

## 실패 처리

- appraisal 근거가 없으면 중립 상태로 되돌리고 추측을 표시한다.
- 관계·사용자 감정의 영구 기록은 명시적 opt-in 없이는 하지 않는다.
- 위기·의료·자해 관련 대화에서 정서 모델은 판단자가 아니며, 별도 안전 정책을 우선한다.
- 사람 대상 평가는 동의 절차와 철회·삭제 경로가 정해진 뒤에만 시작한다.

## 구현 순서

1. 사건 카드 스키마와 30개 합성 카드 작성
2. 순수 함수형 appraisal/state reducer 및 상태 로그 구현
3. baseline policy와 affect-aware policy 구현
4. 단위·회귀·제거 실험 리포트 자동화
5. 결과가 기준을 통과할 때만 LLM 어댑터와 분야별 시나리오를 추가
