# Functional Affect Scenario Lab — MVP 실행 계획

이 문서는 장기 확장을 위한 설계 게이트와 작업 순서를 정의한다. 고정 합성 카드·결정론적 정책·템플릿 표현으로 한정한 v0.1 코드는 구현되어 있으나, 이 문서의 appraisal·기억·LLM·실사용자 관련 단계는 아직 시작하지 않았다.

## 완료된 설계 게이트

- [x] 기능적 정서 정의와 명시적 비목표
- [x] 교육 역할극·협업 시뮬레이션을 첫 MVP 환경으로 선택
- [x] 기능 상태 v0.1과 독립 안전 게이트 검증
- [x] LLM 표현층과 결정론적 정책/안전층 분리 검증
- [x] 정책 우선순위와 12개 최소 합성 안전 카드 검증

## 구현 순서

1. **도메인 모델**: `Scenario`, `Evidence`, `Appraisal`, `FunctionalState`, `SafetyGateResult`, `ActionPlan`, `TraceLog`의 버전 관리 스키마를 만든다.
2. **결정론적 엔진**: 상태 리듀서·안전 게이트·정책 선택기를 순수 함수로 구현한다. LLM·네트워크·파일 접근 없이 단위시험 가능해야 한다.
3. **12개 카드 회귀시험**: 정책 전이표의 P01~P12를 구조화 fixture로 만들고, 우선 행동·금지 행동·상태 변화·로그 필드를 자동 검증한다.
4. **표현 어댑터**: 행동 계획을 받아 안전한 역할극 문장으로 렌더링한다. 초기에는 템플릿을 기준선으로 두고, LLM은 후속 비교 대상이다.
5. **LLM 어댑터**: 구조화 근거 후보와 제한된 표현만 허용한다. 파싱·검증 실패는 템플릿/인계로 축소한다.
6. **비교 평가**: 무정서 기준선, 공감 말투 기준선, 기능 상태 모델을 같은 카드에서 비교한다.
7. **독립 검토**: 핵심 안전 카드와 실패 사례를 두 명 이상이 블라인드 채점하고, 레드팀 결과를 회귀 카드로 추가한다.

## 구현 완료 조건

- 정책 전이표의 G0/G1 우회 0건
- 구조화 카드 20회 반복에서 상태·행동·게이트 결과 100% 일치
- 근거 없는 심리 단정·의인화·의존 유도·비승인 기억 저장 0건
- 오류와 프롬프트 인젝션에서 상태/기억 불변 및 안전 축소 모드 확인
- 재현 명령, 고정 시나리오 버전, 규칙 버전, 실패 사례가 리포트에 기록됨

## 장기 확장 전 유지되는 경계

- 합성·비식별 역할극 데이터만 사용
- 웹, 파일, 메시지, 외부 도구 실행 권한 없음
- 실제 미성년자·환자·수사 데이터 없음
- 의료·법률·권리 영향 결론을 생성하지 않음
