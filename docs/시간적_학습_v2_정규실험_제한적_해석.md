# 시간적 학습 v2 정규 실험 — 제한적 해석

## 대상과 검증 상태

- artifact: `artifacts/temporal_learning_v2/temporal-learning-v2-20260923-02`
- config: 20 seeds, training 600 episodes, evaluation 50 episodes, checkpoints 0/100/300/600
- control: run, `verify --with-audit`, verify-first `replay --with-audit` 모두 exit 0
- public completion 존재, `failure.json` 부재, 각 control stdout/stderr 0 bytes

이는 합성 환경에서의 결정론적 evidence 생성·audit join·재생 가능성을 확인한 것이다. 실제 감정, 의식, 인간 발달 또는 사람에 대한 일반화를 확인한 것은 아니다.

## 사전 기준 결과

L(학습 전후 AFFECT의 held-out reward/step 변화)은 통과했다.

| 조건 | 평균 변화 | qualifying seeds | 판정 |
| --- | ---: | ---: | --- |
| test_A | +0.2075867 | 20 / 20 | pass |
| test_B | +0.3502200 | 20 / 20 | pass |

S(AFFECT가 COUNTS 및 FAILURE_TRACE보다 우월함)는 네 비교 모두 실패했다. 평균 차이는 약 -0.00225에서 +0.00282였고, threshold +0.02 및 16 qualifying seeds 기준을 만족한 비교는 없었다.

따라서 이 정규 artifact는 합성 과제에서 학습 전후 변화가 있었음을 보이지만, 현재 사전 기준으로 AFFECT 구성요소의 독립적 비교 우월성을 보이지 않는다.

## 보조 evidence의 범위

persistence와 safety는 통과했다. Brier, context TRY sample, scalar-neutral, context-token permutation은 값·표본·counterfactual evidence가 생성되고 strict verifier에서 독립 재계산됐음을 기록한다. 이들의 `pass`는 evidence 생성·검증 상태일 뿐, 방향성 효과·인과 기여·AFFECT 우월성의 판정이 아니다.

## 금지된 후속 행동

- S 미달을 뒤집기 위한 scalar 계수, threshold, seed, split 또는 모델 선택의 사후 변경
- S 미달을 숨기고 L 통과만으로 기능적 정서 기여를 주장하는 해석
- 합성 결과를 실제 정서·의식·인간 발달의 증거로 표현하는 주장

후속 탐색은 새 가설, 고정된 acceptance criterion, 새 split/seed policy, 새 run-id를 사전 등록하고 별도 승인받은 뒤에만 수행한다.
