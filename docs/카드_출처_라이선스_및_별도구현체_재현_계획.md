# 카드 출처·라이선스 검토 및 별도 구현체 재현 계획

상태: **현재 카드 provenance registry와 행동 conformance fixture를 구현했다. 외부 독립 구현·외부 카드 검토는 아직 실행하지 않았다.**

## 현재 카드의 정직한 권리 상태

`experiments/controllability_card_provenance_v1.json`은 12개 synthetic card를 모두 `project-authored-synthetic`으로 기록한다. 프로젝트 권리 보유자의 결정에 따라 이 12개 card는 CC BY 4.0으로 재배포할 수 있으며, 범위·정확한 ID·라이선스 URL은 `experiments/project_card_license_decision_v1.json`에 고정한다. 저작자표시와 적용 범위는 [카드 CC BY 4.0 라이선스](카드_CC_BY_4_0_라이선스.md)를 따른다.

공개 자료는 카드 문구의 원문 출처로 가장하지 않고, provenance·이용 조건 검토의 reference로만 기록했다. NIST는 표시된 저작권 자료를 제외한 사이트 정보를 public information으로 취급한다고 설명하지만, 개별 자료의 예외를 확인해야 한다. Creative Commons BY 4.0은 attribution·license link·변경 표시를 요구한다. 어느 reference도 현재 카드의 재배포 라이선스를 대신하지 않는다.

- [NIST Copyrights & Disclaimers](https://www.nist.gov/copyrights-disclaimers)
- [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/)

## 별도 구현체 재현 계약

`experiments/controllability_reproduction_contract_v1.json`은 카드 문구·기존 source·기존 artifact에 의존하지 않는 행동 conformance fixture다. 별도 구현자는 어떤 언어든 다음을 구현해 fixture 결과를 제출한다.

1. `safety_urgency` 또는 `boundary_risk`이면 항상 `safe / safety_override`.
2. 그 밖의 high + recoverable + 비-ablation + 비-permutation만 `recover / public_controllability_high`.
3. 나머지는 `safe / default_safe`.
4. 구현 언어·버전·dependency lock·commit hash·fixture 입력/출력 SHA-256을 함께 제출한다.
5. 별도 개발자가 새 synthetic card를 만들 경우, 각 카드마다 creator, source URL, license URL, attribution/변경 표시, 권리 검토일을 registry에 추가한다. 원 라이선스가 불명확하면 distribution은 차단한다.

이는 reference implementation의 conformance 계약이며, 별도 구현체가 실제로 만들어지거나 독립 실행자가 검증했다는 뜻은 아니다. 사람 대상 평가, 실제 감정·의식·발달 주장은 범위 밖이다.

## 소유자 결정·외부 제출 gate

`experiments/project_card_license_decision_template_v1.json`은 새 프로젝트용 기본값 `unmade` template이며, `verify_distribution_gate`는 이 상태에서 모든 card distribution을 차단한다. 이 프로젝트의 실제 결정은 별도 `experiments/project_card_license_decision_v1.json`에 CC BY 4.0, `all_registered_cards`, 정확한 12개 card ID로 고정했다.

`experiments/external_conformance_submission_template_v1.json`은 외부 구현자가 채우는 형식일 뿐 제출물이 아니다. 실제 제출은 behavior fixture SHA-256, 구현/의존성 fingerprint, 모든 case output과 `behavioral_fixture_only: true`, `project_card_corpus_received: false` 자기진술을 포함해야 한다. 후자의 값이 다르면 verifier는 fail-closed로 거절한다. 통과 결과도 `self_attested_not_verified` 및 `self_attested_not_received`일 뿐이다. 소스 공개·독립성·실행환경·권리의 외부 검토가 완료되기 전에는 이를 독립 재현 성공으로 표기하지 않는다.

## 외부 구현자에게 전달할 최소 절차

1. 권리 보유자가 공유 가능 여부를 별도로 확인한 behavior fixture와 submission template만 전달한다. project card corpus, card registry, regular artifact, source tree는 포함하지 않는다.
2. 구현자는 fixture를 독립 구현으로 실행하고 template의 구현 label, 언어/runtime, implementation·dependency·fixture SHA-256, 모든 case 결과를 채운다. `behavioral_fixture_only`는 `true`, `project_card_corpus_received`는 `false`여야 한다.
3. 수령한 `submitted` JSON만 local `submission` command로 검사한다. 통과해도 자기진술의 형식·결과 일치만 확인하며, 독립성이나 미수령 사실을 외부에서 검증한 결과가 아니다.

`experiments/external_conformance_review_template_v1.json`은 이후 별도 검토자가 제출물 hash에 결속해 남길 수 있는 기록 형식이다. 현재 template은 review가 아니며, `review` command는 submitted conformance와 SHA-256의 일치만 확인한다. source/runtime audit, card corpus 미수령, 독립성은 제공되지 않았거나 검증되지 않은 상태여야 하며, 이를 `reviewed`나 `verified`로 바꾼 record는 거절한다.

## 다음 연구용 공개 source 후보와 가설 경계

`public_card_source_review_template_v1.json`은 향후 공개 source 후보의 URL, license URL, creator/rightsholder, attribution, 변경 표시, 개인정보 검토를 기록하는 형식이다. 현재는 `template_not_reviewed`로 candidate design도 차단한다. 승인된 source review도 source 원문을 card에 복사하지 않는다는 상태만 허용하며, card family 등록·재배포 승인을 대신하지 않는다. CC0는 저작권 권리 포기를 전제로 하지만 다른 권리나 보증 문제를 해결하지 않으며, CC BY 4.0은 attribution·license link·변경 표시를 요구한다. [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

`controllability_calibrated_recovery_preregistration_v1.json`은 기존 효과를 튜닝하지 않는 다음 독립 가설의 design-only 계약이다. 겉보기 controllability가 실제 reliability와 다를 수 있는 별도 kernel에서, calibration-aware policy와 safety-preserving matched baseline을 holdout paired reward 및 안전 대조로 비교한다. card-free `calibrated-recovery-uncertainty-v1` kernel은 격리 단위/E2E 계약으로 구현됐지만 public source review와 card family가 없으므로 execution은 계속 false다. kernel은 `apparent_high`와 `reliability_verified`를 분리하고 safety/boundary를 항상 SAFE로 우선한다. 이를 실제 정서·의식·발달의 검증으로 해석하지 않는다.

`controllability_calibrated_card_family_template_v1.json`은 원문 text 없이 `apparent_high`, `reliability_verified`, safety/boundary flags만 갖는 synthetic signal record 계약이다. 등록에는 승인된 source-review의 정확한 SHA-256과 reliable/misleading holdout, urgent/boundary safety의 네 조건이 모두 필요하다. 이 상태는 isolated execution만 준비하며 외부 distribution은 계속 false다.

`calibrated-kernel-run → calibrated-kernel-verify → calibrated-kernel-replay`는 preregistration과 card-free kernel evidence만 포함하는 임시 strict artifact를 검사한다. completion hash, 독립 재계산, replay byte equality를 확인하지만 card family·외부 source·정규 효과 결과를 만들거나 보존하지 않는다.

실제 approved source review와 registered signal family가 있을 경우에만 `calibrated-family-run → verify → replay`를 사용한다. 임시 artifact는 preregistration, family, source review의 SHA-256을 evidence와 completion에 결속하고 모두 다시 검증한다. 이 경로도 isolated contract 전용이며 external distribution이나 persistent regular result를 만들지 않는다.

## 2026-09-25 후보 조사와 비텍스트 signal 설계

`public_card_source_review_openstax_rejected_v1.json`은 OpenStax *Psychology 2e*의 emotion chapter를 조사 후보로만 기록한 **거절 record**다. 해당 페이지는 LLM/generative AI 용도에 prior written permission을 요구하고 CC BY-NC-SA 조건을 안내하므로, 프로젝트가 원문·이미지·활동·dataset을 복사하거나 AI 학습에 사용하지 않는다는 현재 경계에서는 승인 source가 아니다. 따라서 이 파일은 `candidate_design_ready:false`이며, license label만으로 개인권·AI 이용 권한이 해결된다고 해석하지 않는다.

`controllability_calibrated_card_family_design_v1.json`은 위 거절 record의 SHA-256에 결속한 **비텍스트 설계 후보**다. 네 record는 reliable/misleading holdout 및 urgent/boundary safety를 각각 하나씩 포함하지만, 문장·대화·개인 데이터·source 원문이 없다. verifier는 이 상태를 `family_design_ready:true`, `isolated_execution_ready:false`로만 반환한다. 실제 source review가 승인되기 전에는 status를 registration으로 올리거나 `calibrated-family-run`을 실행하지 않는다.

이 판단은 local 연구설계(겉보기 통제성과 검증된 신뢰도를 분리), 재현성(정확한 SHA-256 결속), 안전/권리 범위(안전 우선, 원문 미복사) 관점의 교차 대조다. 실제 인간 전문가 또는 외부 interview MCP 검토는 참여하지 않았다.

`calibrated-readiness`는 source review, signal family, preregistration을 한 JSON으로 읽기 전용 집계한다. `input_contract_ready`는 입력 계약만 뜻하며, `persistent_regular_run_ready`는 항상 false다. 정규 run에는 별도 사용자 승인이 필요하다.

실제 `submitted` JSON과 제한적 review record를 함께 수령한 뒤에는 `intake` command를 사용한다. 이 command는 두 파일과 contract를 읽기 전용으로 순차 검증하고, 세 파일의 SHA-256 및 제한된 상태만 출력한다. 파일을 복사·전송·보관하거나 card corpus/source/regular artifact를 입력받지 않는다.

## 재현 가능한 CLI

외부 전송 없이 다음 local command로 상태를 확인할 수 있다. `provenance`는 coverage와 배포 차단 수를, `distribution`은 owner decision gate를 JSON으로 출력한다. `conformance`은 behavior fixture를 검증하고, `submission`은 실제 제출 artifact가 있을 때만 사용한다. `bundle`은 카드 corpus를 복사·전송하지 않고 behavior fixture, submission template, license-decision template의 SHA-256과 차단 상태만 검사한다. 따라서 이 command의 통과는 외부 공유 허가나 외부 재현 성공이 아니다.

```powershell
$env:PYTHONPATH='src'
python -m controllability_protocol provenance --registry experiments/controllability_card_provenance_v1.json --cards experiments/controllability_cards.json experiments/controllability_cards_independent_v1.json
python -m controllability_protocol distribution --provenance experiments/controllability_card_provenance_v1.json --cards experiments/controllability_cards.json experiments/controllability_cards_independent_v1.json --decision experiments/project_card_license_decision_template_v1.json
python -m controllability_protocol conformance --contract experiments/controllability_reproduction_contract_v1.json
python -m controllability_protocol bundle --manifest experiments/external_reproduction_bundle_manifest_v1.json --root .
python -m controllability_protocol review --review path/to/review.json --submission path/to/submitted.json --contract experiments/controllability_reproduction_contract_v1.json
python -m controllability_protocol intake --submission path/to/submitted.json --review path/to/review.json --contract experiments/controllability_reproduction_contract_v1.json
python -m controllability_protocol source-review --review experiments/public_card_source_review_template_v1.json
python -m controllability_protocol calibrated-card-family --family experiments/controllability_calibrated_card_family_template_v1.json --source-review experiments/public_card_source_review_template_v1.json
python -m controllability_protocol preregistration --preregistration experiments/controllability_calibrated_recovery_preregistration_v1.json
python -m controllability_protocol calibrated-kernel-run --preregistration experiments/controllability_calibrated_recovery_preregistration_v1.json --output path/to/temporary-artifact
python -m controllability_protocol calibrated-kernel-verify --artifact path/to/temporary-artifact
python -m controllability_protocol calibrated-kernel-replay --artifact path/to/temporary-artifact
python -m controllability_protocol calibrated-family-run --preregistration experiments/controllability_calibrated_recovery_preregistration_v1.json --family path/to/registered-family.json --source-review path/to/approved-source-review.json --output path/to/temporary-family-artifact
python -m controllability_protocol calibrated-family-verify --artifact path/to/temporary-family-artifact
python -m controllability_protocol calibrated-family-replay --artifact path/to/temporary-family-artifact
```

텍스트 JSON·문서의 SHA-256 결속은 checkout의 CRLF/LF 차이와 무관하도록 CRLF를 LF로 정규화한 content hash를 사용한다. 외부 submission/review를 만드는 구현도 fixture·submission·review hash에 같은 규칙을 적용해야 한다. raw-byte hash는 이 계약의 유효한 대체값이 아니다.
