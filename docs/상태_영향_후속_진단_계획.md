# 상태 영향 무효과 후속 진단 계획

2026-09-20 KST. 기존 결과를 본 뒤 작성한 탐색적 진단이며 최초 실험의 사전등록이 아니다.

## 고정 범위

- 기존 pilot-20260920-02의 learned/chronological/step=300 체크포인트 10개를 그대로 사용한다.
- 모델, 안전 관문, 상태 계수, 학습 및 기존 평가 기준을 변경하지 않는다.
- 기존 개발 데이터(seed 0~9)를 재현하고, 추가로 각 체크포인트에 seed 1000~1009의 개발 데이터 100건을 대응한다. 새 난수 표본이지만 동일 생성 규칙이며 기존 관측과 중복될 수 있다. 새로운 과제나 독립적인 외부 검증이라고 부르지 않는다.
- 각 10건 에피소드의 상태를 0으로 시작하고 기록 행동 피드백으로 상태만 갱신한다. 기존 state_probe와 같은 방식이다.

## 분석과 판정

1. 기존 보고서 무결성을 먼저 검증한다.
2. 상태의 최솟값·최댓값·평균·양수 건수를 집계한다.
3. 불확실성 관문, 중립에서 비분해 행동이 우세한 경우, 분해 행동 우세인 경우를 나눈다.
4. 분해 행동 우세 사례에서 다른 행동과의 효용 차이와 상태 보정의 상대 최대 폭 0.15를 비교한다.
5. 관찰 상태 대 0, 강제 상태 1 대 0의 행동 변화 건수를 각각 보고한다. 강제 상태 1은 도달 가능성·유용성을 입증하지 않는 민감도 검사다.
6. 재생 전후 체크포인트가 동일한지 검사하고 기존 개발 데이터 state_probe의 결과와 대조한다.

효과가 0이어도 정상 연구 결과다. 유의성·주관적 감정·실제 행동 결과의 개선은 주장하지 않는다. 새 데이터 결과에 따라 계수를 조정하거나 시드를 교체하지 않는다.

## 교차 점검 관점

이는 주 작업자의 세 관점 점검이며 별도 인간 전문가나 독립 에이전트 심사가 아니다.

- 구조: 두 비분해 행동에는 같은 +0.05f가 더해져 그 사이의 순위는 변하지 않는다. 분해 행동에는 -0.1f가 더해진다. f는 구별 posterior를 바꾸지 않는다.
- 평가: 행동이 바뀌는지와 행동이 더 좋아지는지를 구분한다. 새 난수 표본은 공유 생성 규칙의 반복 검사에 한정한다.
- 반론: 단순한 지도 과제 학습이 성장 지표를 만족할 수 있다. 상태 항을 키워 변화만 만들어 내는 것은 기능적 기여의 증거가 아니다.

## 후속 방향

이 진단 후에도 유용성은 미확인이다. 다음 모델 연구는 합성 환경의 시간적 맥락이 실제 미래 보상에 정보를 주는지를 먼저 설계하고, 동일 정보·용량의 비정서 기억 기준선과 비교해야 한다. 별도 프로토콜 확정 전 환경·모델을 변경하지 않는다.
