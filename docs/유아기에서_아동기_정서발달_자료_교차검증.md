# 유아기에서 아동기로 — 사고·정서 발달 자료와 교차검증

수집일: 2026-09-18. 범위는 유아기에서 학령기 아동기(대략 5~11세)로의 점진적 전이다. 이 문서는 발달심리·정서/교육심리·AI 안전 관점의 문헌 기반 사전 검토이며, 임상 진단이나 개인 평가 기준이 아니다.

## 교차검증 결론

아동기는 유아기의 공동조절이 “자기조절로 완전히 교체”되는 시기가 아니다. 가정의 돌봄 관계를 바탕으로 학교·교사·또래·규칙이라는 새 맥락에서 언어적 계획, 주의 전환, 재평가, 갈등 협상, 관점 전환을 연습하는 과정이다. 연령·기질·언어·문화·장애/신경다양성·스트레스 경험에 따른 개인차가 크다.

```text
공동조절(도움·안정)
      ↓
규칙을 기억하며 멈추고 기다리기
      ↓
상대의 정보·목표·관점을 분리하기
      ↓
새 증거로 해석을 고치고 협력적으로 회복하기
```

| 자기개념 | 구체적 선호·행동 중심 자기평가에서 능력·관계·정서 등 여러 영역을 더 분화해 본다. | 단일 성격/발달 점수로 사람을 분류하지 않는다. | [자기개념 검토](https://pmc.ncbi.nlm.nih.gov/articles/PMC11734892/) |

## 자료가 지지하는 설계 원칙

1. 정서를 단일 라벨이 아닌 `목표, 규칙, 관계, 피해 가능성, 불확실성, 통제 가능성, 기억 신뢰도`의 평가 상태로 다룬다.
2. “공감”은 상대 마음을 판독하는 기능이 아니라, 확인·질문·선택권·도움 연결을 제안하는 상호작용 정책으로 제한한다.
3. AI의 성장은 나이가 아니라 검증 가능한 역량 게이트로 표현한다.
4. 새 근거가 오면 기존 해석과 응답을 명시적으로 수정하고, 그 이유를 남긴다.

| 1. 규칙 유지 | 차례·약속·목표를 기억하고 즉시 반응을 멈춤 | 상대가 말하는 중일 때 끼어들지 않고 대기한다. |
| 2. 좌절 회복 | 실패 후 재시도·휴식·도움 요청을 비교 | 반복 실패 후 공격적 응답 대신 원인 가설을 만든다. |

| 4. 재평가·수정 | 새 증거로 초기 해석을 갱신 | 비판처럼 보였던 발화가 안전 경고였음을 반영한다. |
| 5. 협력적 해결 | 선택권·사과·수정·중재를 제안 | 자원 충돌에서 공정한 대안을 제시한다. |

## 평가와 금지선

평가는 감정적으로 보이는 말투가 아니라 `근거 충실도`, `불확실성 보정`, `충동 억제`, `회복 전략`, `관점 공정성`, `수정 가능성`, `감사 가능성`으로 한다.

- AI가 유아·아동처럼 애착·고통·의식·도덕적 책임을 실제 경험한다고 주장하지 않는다.
- 표정·음성·텍스트만으로 감정, 성격, 거짓말, 위험성을 단정하지 않는다.
- 발달/정서 상태를 의료·수사·채용·복지 등 권리 영향 판단의 입력으로 사용하지 않는다.
- 실제 아동 데이터 없이 합성 카드와 저위험 시뮬레이션으로 시작한다.
- 발달 이정표는 진단·정상성 판정 도구가 아니다. [CDC 설명](https://www.cdc.gov/act-early/milestones/key-points.html)
