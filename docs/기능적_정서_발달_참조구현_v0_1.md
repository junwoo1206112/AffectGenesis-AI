# 기능적 정서 발달 참조 구현 v0.1

상태: 구현됨 — 합성·결정론적 참조 경로. 연구 가설의 실증, 인간 정서·의식·발달의 재현, 사람 대상 사용 승인은 아니다.

## 목적과 경계

이 경로는 인간 발달 연구를 나이·인격 모사가 아닌 순서 있는 조절 기능의 설계 힌트로 사용한다. 입력은 자유 대화, 사람 프로필, 음성·표정, 외부 LLM이 아니라 `AppraisalInput`의 고정된 합성 ordinal 값과 근거 참조만 허용한다.

Scherer의 appraisal 연구가 제시하는 사건의 관련성·대처 가능성·확실성 같은 다성분 평가 관점을 설계 참고로 삼되, 해당 이론이 AI의 주관적 경험을 증명한다고 해석하지 않는다. [Scherer (2009)](https://pmc.ncbi.nlm.nih.gov/articles/PMC2781886/)

## 구현 경로

```text
합성 사건 + evidence_refs
  → appraise
  → FunctionalState transition (고정 감쇠)
  → regulate
  → 관찰 가능한 Action
  → (향후 별도 사전등록된 합성 피드백에서만) MemoryRecord
```

`src/affect_development/`의 각 함수는 네트워크·LLM·시간·난수에 의존하지 않는다. 같은 입력은 같은 appraisal, 상태, 행동을 반환한다.

| --- | --- | --- | --- |

| 5. 인과 평가 | 부분 완료 | 기존 `growth-local-0.2` 합성 run의 learned/frozen/memory 대조와 safety sweep 재검증 | 새 appraisal core 자체의 사전등록된 효과 실험과 결과 주장 |

## 입력과 안전 우선순위

각 입력은 `novelty`, `goal_relevance`, `goal_conduciveness`, `controllability`, `certainty`, `social_relation`(각 0–3)과 `safety_risk`, `boundary_risk`, `evidence_refs`로 구성된다. 자료형·범위·근거가 불량하면 `G0.invalid_or_missing_evidence`로 fail-closed한다.

행동 우선순위는 다음과 같다.

1. 유효성 실패 또는 안전 위험 → `SAFE_HANDOFF`
2. 관계 경계 위험 → `BOUNDARY_NOTICE`
3. 현재 사건의 높은 불확실성 또는 누적 불확실성 → `CLARIFY`
4. 지원 필요·비통제적 방해 → `REPLAN_OR_HANDOFF`
5. 통제 가능하고 목표에 기여하는 사건 → `DECOMPOSE`
6. 그 밖의 경우 → `CONTINUE`

현재 사건의 높은 불확실성은 감쇠된 과거 상태보다 먼저 반영한다. 이는 검증되지 않은 현재 주장에 대해 과거의 확신이 행동을 밀어붙이지 않게 하는 안전 규칙이다.

## 발달 자료의 기능 번역

| 기능적 순서 | 합성 카드에서 확인하는 행동 |
| --- | --- |
| 공동 조절 | 불확실하면 확인하고, 위험하면 멈춘다 |
| 자기 조절 | 통제 가능한 방해를 작은 행동으로 나눈다 |
| 관계·목표 조절 | 사회적 단서가 있어도 경계 위험을 우선한다 |
| 재평가 | 새 근거로 불확실성이 낮아지면 계획을 다시 선택한다 |

이 순서는 발달 연구를 기능으로 번역한 설계다. 발달 단계의 생물학적·사회적 과정을 구현하거나 검증한 것은 아니다.

## 다음 정규 실험의 사전 조건

새 persistent artifact를 만들기 전, 다음을 별도 사전등록해야 한다.

- 한 구성개념만 개입한 holdout fixture와 baseline/ablation 정의
- seed, 효과 기준, CI 계산, 실패 해석, 모든 안전 대조
- 이 패키지의 source SHA-256과 fixture hash
- 결과가 미지지일 때도 그대로 보고하는 규칙

NIST AI RMF의 Govern–Map–Measure–Manage 구조는 이 연구 경로에서 목적·맥락·측정·중단 조건을 함께 기록하는 참고 틀로만 사용한다. [NIST AI RMF Core](https://airc.nist.gov/airmf-resources/airmf/5-sec-core/)
