# Generated research artifacts

This directory is intentionally excluded from the normal Git baseline except
for this note. The local generated corpus is currently several gigabytes and
contains large JSONL evidence and restricted-audit material that should not be
published through an ordinary Git push by accident.

The repository tracks the code, experiment contracts, manifests, source hashes,
verification commands, and reports needed to reproduce artifacts. Before any
artifact is shared, select an explicit channel and review its license, privacy,
and size constraints (for example Git LFS, a release attachment, or a controlled
research archive). This note does not authorize external distribution.
